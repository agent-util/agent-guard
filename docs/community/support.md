# Support

Use [GitHub Discussions](https://github.com/agent-util/agent-guard/discussions) for integration questions and design conversations. Include:

- Agent Guard and Node.js versions
- Operating system
- Enforcement adapter
- Minimal configuration with secrets removed
- Expected and actual behavior

Use the [issue templates](https://github.com/agent-util/agent-guard/issues/new/choose) for reproducible bugs and feature proposals.

::: danger Security reports
Do not disclose suspected vulnerabilities publicly. Use [GitHub private vulnerability reporting](https://github.com/agent-util/agent-guard/security/advisories/new).
:::

Community support is best effort. Sponsorship supports maintenance but does not purchase a service-level agreement or priority disclosure.
