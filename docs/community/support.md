# Support

Use the [support-question form](https://github.com/agent-util/agent-guard/issues/new?template=support_question.yml) for public installation, configuration, and integration help. Use the [installation feedback form](https://github.com/agent-util/agent-guard/issues/new?template=installation_feedback.yml) when reporting first-time setup friction. Include:

- Agent Guard and Node.js versions
- Operating system
- Enforcement adapter
- Minimal configuration with secrets removed
- Expected and actual behavior

Use the [issue templates](https://github.com/agent-util/agent-guard/issues/new/choose) for reproducible bugs and feature proposals.

Maintainers recruiting first-time users should follow the [three-person installation test](/community/installation-testing). A prepared [good first issue backlog](/community/good-first-issues) is available for contributor onboarding.

::: danger Security reports
Do not disclose suspected vulnerabilities publicly. Use [GitHub private vulnerability reporting](https://github.com/agent-util/agent-guard/security/advisories/new).
:::

Community support is best effort. Sponsorship supports maintenance but does not purchase a service-level agreement or priority disclosure.
