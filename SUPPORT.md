# Support

## Questions and usage help

Use the [support-question form](https://github.com/agent-util/agent-guard/issues/new?template=support_question.yml) for public integration questions and general help. Use the [installation feedback form](https://github.com/agent-util/agent-guard/issues/new?template=installation_feedback.yml) for first-time setup problems. Include your Agent Guard version, Node.js version, operating system, enforcement adapter, and a minimal configuration with all secrets removed.

## Bugs and feature requests

Use the repository's [issue templates](https://github.com/agent-util/agent-guard/issues/new/choose). Search existing issues first and provide a minimal reproduction for bugs.

## Security issues

Do not disclose suspected vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) and use GitHub's private security advisory process.

Community support is provided on a best-effort basis. Sponsorship supports maintenance but does not purchase a service-level agreement or priority disclosure.
